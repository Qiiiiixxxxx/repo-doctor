## 1. Project description

**repo-doctor** is a zero-dependency CLI that audits the health of any Git repository in seconds. It checks for the problems that quietly kill small open-source projects: missing README/LICENSE, merged branches never deleted, uninformative commit messages, multi-megabyte binaries committed without LFS, accidentally leaked secrets (private keys, AWS keys, hard-coded tokens), and long maintenance gaps. It outputs a human-readable report with a 0–100 health score, or JSON with a `--fail-under` gate for CI pipelines.

The project is deliberately dependency-free (Python ≥ 3.9 stdlib + git) so it runs in any CI environment. It ships with a unittest suite that builds real temporary git repositories, and GitHub Actions CI across Ubuntu/Windows/macOS on Python 3.9–3.12.

Repo: https://github.com/Qiiiiixxxxx/repo-doctor

I use Codex daily as my pair programmer for this project: scaffolding new checks from a one-line description, generating edge-case tests (weird repo states, non-UTF-8 files, bare repos), reviewing my own PRs before merging, and drafting release notes. Concretely, Codex helps me:
